Methods and data limits
  • FM-Arena: standard test table per patch. Tests = matches ÷ 450 (each test is 450 matches). Points, GF, GA and GD are converted from the published per-38 figures (rounded). FM-Arena does not publish W/D/L, so there is no Win %.
  • FMAX Tactic Lab (getfmax.com): public JSON API, every match-engine version it lists. W/D/L, GF and GA are real totals from standardised tests; points are recomputed from W/D/L, so for some tactics they differ slightly from FMAX's own ranking score. The number of tests is not published. Formation comes from each tactic's detail page (read once, then reused).
  • metaFM (metafm.net): current leaderboard plus the leaderboards of older patches (27.0.1). Each tactic plays up to 8,008 matches against the same AI game plans with identical players. W/D/L is derived from Win % and PPG; GF/GA are converted from the published per-38 figures. The number of tests is not published.
  • FMDelicious (fmdelicious.com): official 27.1.0 ranking, one protocol, 6,048 matches per tactic. Exact W-D-L comes from each tactic's page (read once, then reused while the match count is unchanged); GF/GA are converted from the per-38 figures. Formations are the site's own labels (marked *). The FM27 archive (beta) adds one 38-match league season at Spurs (top), Bournemouth (mid) and Leeds (bottom), points only; sacked seasons and built-in presets without results are left out.
  • Sortitoutsi: each row is one user-submitted test (team, W/D/L, real GF/GA). Small samples (a few matches) are noisy, so rows are filtered to matches ≥ 38 by default.
  • FM-Tactic-Hub (fm-helper.de): 380 matches for each team tier (Top teams / Mid-table / Relegation). W/D/L is derived from Win % and points; GF/GA and the number of tests are not published.
  • FM Scout, FMSite.net, FM Base, YouTube: catalogues only (views, downloads). Results sit in images or free text, so there is no test data; formations marked (*) are guessed from the title. YouTube needs an API key, or channel IDs for the RSS fallback, in config.json.
  • fmkorea: blocks automated access with a Cloudflare captcha, so enter it by hand in data/manual.csv (column source = fmkorea). Facebook has no usable API either; use the same file for tactics seen there. The FM27 Steam Workshop (tactic subscriber counts) could not be reached from this network: the Steam domains do not resolve.
  • Leader tiles show the top row for each metric under the current filters (per 38 games, so small samples can lead: raise “Matches ≥” for steadier leaders). “Most downloads” also counts catalogue rows without test data; each site counts its own downloads, never summed across sites.
  • Team tiers (Elite / Top / Sub-top / Underdog) are our own rough grouping of the real clubs testers picked on Sortitoutsi, by real-world strength, not FM's reputation values. FM-Tactic-Hub's Top teams / Mid-table / Relegation map to Top / Sub-top / Underdog. Standard-test sources have no tier. Clubs not in the list get no tier; a manual row can set one in a tier column.
  • Formations are recomputed from player positions using FM's naming convention: wing-backs count as defenders (3 centre-backs + 2 wing-backs = “5-…”). Hover a formation cell to see the positions.
  • Units on the charts: each chart has its own Per game / Per 38 / Total buttons (the table keeps the global one). Per game = total ÷ matches; Per 38 = per game × 38; Total = the raw sum. Total favours tactics with more matches, so use Per game or Per 38 to compare tactics with different sample sizes.
  • Comparing sources is for reference only because the test environments differ. Filter to one source when ranking. Chart colours are decorative (rank order, not source): the source is named in each bar label and tooltip.
