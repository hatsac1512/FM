# FM27 Tactic Lab

A local dashboard that combines Football Manager 2027 tactic test results from several sources.
Press **Update** and the server fetches every source in parallel (about 30–60 seconds).

## Run

```
pip install -r requirements.txt
python app.py              # opens http://127.0.0.1:8765
```

On Windows you can also double-click `run.bat`. To update the data without opening the UI: `python app.py --refresh`.

## Deploy on Render (public site)

1. Push this folder to a GitHub repository. `config.json` and `data/tactics.json` are git-ignored: the first one can hold a key, the second is third-party data that the server rebuilds with Update.
2. In Render: **New → Blueprint**, pick the repository. `render.yaml` creates the web service (Python 3.12, `gunicorn`).
3. Open the service's **Environment** tab. `REFRESH_TOKEN` was generated by Render: it is the password for the Update button. Optional: add `YOUTUBE_API_KEY`.
4. Open the service URL. The page says "No data yet": press **Update**, type the token once (the browser remembers it).

Notes:
- Update works from anywhere only when `REFRESH_TOKEN` is set. Without it, Update works only on the computer running the server.
- Some sites may refuse requests from a server's IP address. In a local test FM Scout and FMSite returned 403, so they may fail on the server too; the dashboard then keeps their previous data and says so.
- The free plan stops the service after a period without visitors, so the first visit can be slow (check Render's current plan rules). Its disk is temporary: after a restart or redeploy the data is gone until the next Update.
- Keep one worker (`--workers 1`): the progress of an update is kept in memory.
- Other hosts that read a `Procfile` (Railway, Heroku-style) use the same start command.

Browsers cannot call these websites directly (CORS, and most have no API), so every request goes
through the Python server (`scrapers.py`). Data is stored in `data/tactics.json`.

## Sources and what they provide

| Source | How it is read | Metrics available |
|---|---|---|
| FM-Arena | Standard test table per patch (`/tactic-testing/versions/27/`) | tests (= matches ÷ 450), matches, points, GF, GA, GD (converted from per-38 figures). **No W/D/L or Win %** |
| FMAX Tactic Lab | Public JSON API (`/api/lab/board`), every version it lists | matches (= W+D+L), real W/D/L, GF, GA, downloads. Points are recomputed from W/D/L, so ~13% of tactics differ slightly from FMAX's own score. Formation from each detail page (read once, then reused). No test count |
| metaFM | JSON embedded in the leaderboard page, plus `/versions/<patch>` for older patches | matches, Win %, points, GF, GA, GD, IP/OOP formation. W/D/L derived from Win % and PPG. No test count |
| FMDelicious | Official ranking table (`/tactics?fm_version=FM27&patch_version=…`) and each tactic's results page | 6,048 matches per tactic, exact W-D-L (results page, reused while the match count is unchanged), points, GF, GA (from per-38 figures), formation label. The FM27 archive (beta) adds one 38-match season at Spurs / Bournemouth / Leeds, points only |
| Sortitoutsi | Tactic list and each tactic's detail page | per test: tester, team, W/D/L, GF/GA, matches, IP/OOP formation |
| FM-Tactic-Hub (fm-helper.de) | Ranking per team tier (Top teams / Mid-table / Relegation) | 380 matches per tier, points, Win %, GD; W/D/L derived. No GF/GA |
| FM Scout | FM27 tactics catalogue page | views, downloads, date only; formation guessed from the title |
| FMSite.net | "Tácticas FM27" file category (Spanish community) | downloads, author, date only |
| FM Base | FM27 Tactics forum section | views, replies, date only |
| YouTube | YouTube Data API v3 (needs a key) or per-channel RSS (needs channel IDs) | views, channel, date only |
| fmkorea | Blocked by a Cloudflare captcha | enter by hand in `data/manual.csv` |
| Facebook | No usable API (the Groups API was removed in 2024) | enter by hand in `data/manual.csv` |
| Steam Workshop | Not connected: the Steam domains do not resolve on this network | (would give subscriber counts) |

If a source fails during an update, the dashboard keeps that source's previous data and shows the error in the status bar.
Detail pages (FMAX formations, FMDelicious W-D-L) are reused from the previous `data/tactics.json`, so only new tactics are read again.
When a site changes its HTML, its scraper may break and need a fix in `scrapers.py`.

## YouTube

Copy `config.example.json` to `config.json` (git-ignored, so keys stay off GitHub), then edit it:

```
{ "youtube_api_key": "", "youtube_channel_ids": [] }
```

- **With an API key** (YouTube Data API v3, Google Cloud Console): searches "FM27 tactic". Search costs 100 quota units per call out of 10,000 per day by default (check the live quota in the API console).
- **Without a key**: list channel IDs (`UC...`) in `youtube_channel_ids`; the public RSS feed of each channel is read and only videos that mention FM27 are kept.

Do not share `config.json` once it contains a key. YouTube only exposes title, channel, views and date, never test results.

## Manual entry (fmkorea, Facebook, other sources)

Add rows to `data/manual.csv` (UTF-8) and press Update. Leave unknown columns empty. Example:

```
source,tactic,url,author,patch,team,formation_ip,formation_oop,tests,matches,w,d,l,gf,ga,points,downloads,views,published,note
fmkorea,Tactic name,https://www.fmkorea.com/...,author,27.1,Tottenham,4-2-3-1,4-4-1-1,1,38,25,8,5,80,35,,,,2026-11-20,
```

If `points` is empty it is calculated as 3W + D.

## Charts and team tiers

- Leader tiles at the top: best goal difference, most points, most goals scored, fewest goals conceded (per 38 games, current filters) and most downloads (also counts catalogue rows; each site's own count). Click a tile to open that tactic.
- Charts: top 15 by points, most goals scored, fewest goals conceded and goal difference (all per 38 games; GF/GA charts only use sources that publish GF/GA), plus average points per formation. Click a bar (or its label) to open the tactic's page; click a formation bar to filter the dashboard to that formation.
- The table has a **Team tier** filter (Elite / Top / Sub-top / Underdog). The tiers are our own rough grouping of the clubs testers used (list in `scrapers.py`, `_TIER_CLUBS`), plus FM-Tactic-Hub's Top teams / Mid-table / Relegation and the FMDelicious archive's top / mid / bottom clubs. FM-Arena, FMAX, metaFM and the FMDelicious ranking use mixed standard opponents, so they have no tier. In `data/manual.csv` you can add a `tier` column.

## Reading the numbers

- **Formations** are recomputed from player positions using FM's naming convention: wing-backs count as defenders
  (3 centre-backs + 2 wing-backs = "5-…"), so a tactic the community calls "3-4-3" may show as "5-2-3".
  Hover a formation cell to see the positions.
- **Per tactic** adds up all tests of one tactic; **Each test / context** shows one row per team or team tier.
- The default filter keeps only rows with **at least 38 matches**, because tests of a few matches on Sortitoutsi are very noisy.
- Test environments differ between sources (FM-Arena and metaFM use standard setups, Sortitoutsi uses teams chosen by the tester), so filter to one source when ranking.
- Source colours (the dots) always sit next to the source name; chart bar colours are decorative (rank order, not source).
